❓ How to Use

  1. Upload your data — drag a CSV/Excel file onto the upload zone, or click "Upload File".
  2. Auto-detection — column types (dates, statuses, priorities, agents, categories, numbers) are detected automatically.
  3. Filter — use the Filter Bar to narrow records by date range, status, agent, or any column.
  4. Drill down — click any KPI card or chart bar/slice to jump to the Data Explorer page filtered to those records.
  5. Data Explorer — open the sidebar (☰) → "Data Explorer" to view all rows. Search, sort, paginate, toggle columns, or click a row for full details.
  6. AI Insights — paste an Anthropic API key to unlock summaries, anomaly detection, agent analysis, and Manager Reports.
  7. Export — download the dashboard as PDF, or export filtered data as CSV from the Data Explorer.
